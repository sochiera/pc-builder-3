# Konfigurator

Aktualny ekran to spokojny, ciemny panel z dwiema jednoznacznymi decyzjami i widocznym podsumowaniem. Zielony status oznacza zgodnosc, koralowy blokade. Kazdy przyszly problem powinien zostac wyjasniony prostym jezykiem obok statusu, a nie ukryty w ikonie lub tooltipie.

Projekt nie definiuje jeszcze kompletnego widoku katalogu ani dashboardu, aby nie tworzyc makiety przed ustaleniem kolejnych pionowych sciezek.
